# Mouth Groove

Turns mouth bass and mouth drums into MIDI: a bass track plus kick, snare and hat.

Live app: https://gunby1-adaptive.github.io/mouth-groove/

- `index.html` is the built app (one self-contained file, served by GitHub Pages).
- `src/` holds the sources: `engine.js` (analysis), `template.html` (UI), `sounds.js` (FluidR3 GM samples).
- Rebuild with `python3 src/build.py` from the repo root.
